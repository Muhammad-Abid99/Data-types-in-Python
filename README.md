
# Python Data Types for Beginners

This Jupyter notebook provides a beginner-friendly introduction to Python's built-in data types. It covers core concepts and best practices, making it a valuable resource for anyone new to Python or looking to strengthen their foundational knowledge.

**GitHub Repository:**
🔗 [https://github.com/Muhammad-Abid99/Data-types-in-Python](https://github.com/Muhammad-Abid99/Data-types-in-Python)

---

## 📘 Topics Covered

* **Numeric Types**: Integers, Floats
* **Text Type**: Strings
* **Boolean Type**
* **Sequence Types**: Lists, Tuples, Ranges
* **Set Types**
* **Dictionary Type**
* Best practices and coding tips

## 🖥️ How to Run the Notebook in VS Code

### ✅ Prerequisites

* [Python 3.x](https://www.python.org/downloads/)
* [Visual Studio Code](https://code.visualstudio.com/)
* Python extension for VS Code (with Jupyter support)

### 📥 Steps

1. **Clone the Repository**

   ```bash
   git clone https://github.com/Muhammad-Abid99/Data-types-in-Python.git
   cd Data-types-in-Python
   ```

2. **Open in VS Code**

   ```bash
   code .
   ```


3. **Open the Notebook**

   * Click on the `.ipynb` file in the sidebar.
   * It will open in interactive notebook view.

4. **Select a Python Interpreter**

   Press `Ctrl+Shift+P`, then select:
   **“Python: Select Interpreter”** → Choose the one with Jupyter.

5. **Run the Notebook**

   Use the ▶️ buttons to run each cell, or "Run All" from the top menu.
